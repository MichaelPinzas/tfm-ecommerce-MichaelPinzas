# TFM - Análisis de Comportamiento de Clientes en E-commerce

**Autor:** Michael Pinzas Villalta  
**Máster:** Big Data & Data Engineering - UCM  
**Tutores:** Jorge Centeno y Alberto González

## Descripción

Plataforma de análisis de comportamiento de clientes en e-commerce mediante arquitectura Data Lakehouse con estructura Medallion (Bronze-Silver-Gold).

## Stack Tecnológico

- **Streaming:** Apache Kafka
- **Procesamiento:** Apache Spark
- **Almacenamiento:** Delta Lake
- **Orquestación:** Apache Airflow
- **Visualización:** Power BI
- **Infraestructura:** Docker

## Dataset

- **Fuente:** Kaggle - eCommerce behavior data from Multi Category Store
- **Registros:** 109 millones
- **Tamaño:** ~10GB
